# First 50 builders

The public entry points are the [product page](https://design.tfgstudio.com/), [live component preview](https://aishwaryshrivastav.github.io/AI-First-Design-System/), [npm core package](https://www.npmjs.com/package/ai-first-design-system), and [React bindings](https://www.npmjs.com/package/@ai-first-ds/react). The library is free and MIT licensed.

## Counting users

A builder counts after they use at least one published component in a real project and confirm the implementation or share a link. npm downloads, page visits, GitHub stars, and Storybook views are reach signals. No external implementation has been verified as of 15 October 2026, so the confirmed count is **0/50**.

## Next acquisition experiment

Invite five builders who are actively making an AI interface to implement one prompt, response, or feedback component in their own app. Offer a 20-minute setup session and ask where the package or docs slowed them down. Record only consented, opaque user IDs in the portfolio ledger. If at least three complete an implementation, publish one real use-case walkthrough and submit the public Storybook to relevant design-system and component directories. If fewer than three do, fix their shared installation obstacle before expanding distribution.

The project can later be submitted to [Storybook Showcase](https://storybook.js.org/showcase/about/) through Chromatic. That route requires a published Chromatic project; the current GitHub Pages preview alone does not satisfy its stated submission path.
