# First 50 builders

The public entry points are the [product page](https://design.tfgstudio.com/), [live component preview](https://aishwaryshrivastav.github.io/AI-First-Design-System/), [npm core package](https://www.npmjs.com/package/ai-first-design-system), and [React bindings](https://www.npmjs.com/package/@ai-first-ds/react). The library is free and MIT licensed.

## Counting users

A builder counts after they use at least one published component in a real project and confirm the implementation or share a link. npm downloads, page visits, GitHub stars, and Storybook views are reach signals. No external implementation has been verified as of 15 October 2026, so the confirmed count is **0/50**.
