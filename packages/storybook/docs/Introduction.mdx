# AI-First Design System

This open-source library provides Web Components and React bindings for common AI product interactions. Browse the live examples, then bring the components you need into your app.

## What the components cover

- Mark generated content with an AI label.
- Let people inspect an explanation and give feedback.
- Render a response as it streams and show useful loading or error states.
- Display a confidence value supplied by your product when that value has a clear meaning.

## 🏗️ Architecture

### Framework-Agnostic Web Components
The core is built with [Lit](https://lit.dev/) and uses standard custom elements. React bindings are published separately. Vue, Svelte, and other frameworks can consume the core Web Components with their own custom-element integration; dedicated wrappers are not published.

### Modern Tech Stack
- **Web Components** - Native browser support
- **TypeScript** - Component types
- **Design tokens** - CSS custom properties and an optional Tailwind configuration
- **Vite** - Package and documentation builds

## 🎨 Design Principles

Based on research from leading design systems:

### 1. Transparency
Show when content is generated by AI.

**Reference:** [IBM Carbon for AI](https://carbondesignsystem.com/guidelines/carbon-for-ai/)

### 2. Explainability
AI decisions should be understandable through progressive disclosure.

**Reference:** [SAP Fiori Explainable AI](https://experience.sap.com/fiori-design-web/explainable-ai/)

### 3. Human-Centered
Keep people involved when a generated result needs review.

**Reference:** [PatternFly AI Guidelines](https://www.patternfly.org/patternfly-ai/ai-guidelines/)

### 4. Contextual Assistance
AI provides help when and where it's needed.

**Reference:** [Emplifi Soul Design System](https://soul.emplifi.io/)

### 5. User Control
Give people a way to correct or reject a suggestion where the product permits it.

**Reference:** [Microsoft HAX Toolkit](https://www.microsoft.com/en-us/haxtoolkit/ai-guidelines/)

## 📦 Installation

```bash
# Core components (framework-agnostic)
npm install ai-first-design-system

# React wrappers
npm install @ai-first-ds/react

# Design tokens
npm install @ai-first-ds/tokens
```

## 🚀 Quick Start

### Web Components in a bundled app

Import the package in your Vite or other bundled app's JavaScript entry file:

```js
import 'ai-first-design-system';
```

Then use the custom elements in HTML:

```html

<ai-button variant="primary">Click me</ai-button>
<ai-chat-message role="ai">Hello!</ai-chat-message>
```

### React

```jsx
import { AIButton, AIChatMessage } from '@ai-first-ds/react';

function App() {
  return (
    <>
      <AIButton variant="primary">Click me</AIButton>
      <AIChatMessage role="ai">Hello!</AIChatMessage>
    </>
  );
}
```

## 📚 Component Categories

### Base Components (AI-Enhanced)
The published base components are a button, input, and badge. The AI components include chat, prompt input, streaming text, labels, feedback, explanations, loading states, and error recovery.

### AI-Specific Components
Purpose-built for AI interactions:
- **Chat Interface** - Complete conversational UI
- **Streaming Text** - Token-by-token generation
- **AI Labels** - Clear AI indicators
- **Prompt Input** - Advanced prompt composer
- **Skeleton Loaders** - AI-aware loading states
- **Confidence Meters** - Display a score supplied by your application

## Accessibility

Components include keyboard and ARIA patterns where implemented. Test contrast, focus behavior, and assistive-technology support in your product before making a compliance claim.

**Reference:** [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/)

## 🎨 Customization

Extensive theming support:

```css
:root {
  --ai-primary-color: #your-brand-color;
  --ai-font-family: 'Your Font', sans-serif;
  --ai-border-radius: 8px;
}
```

Or use our Tailwind configuration:

```js
import baseConfig from '@ai-first-ds/tokens/tailwind';

export default {
  ...baseConfig,
  content: ['./src/**/*.{js,jsx,ts,tsx}'],
};
```
